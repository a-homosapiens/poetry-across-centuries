# Poetry Across Centuries

**Modern & Classic Western Poetry: A Cross-Century Conversation**

A 9th-grade poetry curriculum built as a static website. Ten thematic modules each pair a foundational classic poem with a modern or contemporary response, tracing how Western poetry's form, tone, and perspective have shifted across roughly twenty-seven centuries — from Homer to Dylan Thomas.

## What's here

- **`index.html`** — landing page listing all ten pairings and the eighteen poets featured
- **`modules/`** — one page per pairing (`module-1.html` … `module-10.html`), each with:
  - a **Student** and **Teacher** edition toggle (background, close-reading guidance, guiding questions, annotation prompts)
  - a **day/night** mode toggle
  - the two poems presented in reading sequence, plus a vocabulary/allusions glossary
- **`poets/`** — a short biography page for every poet featured, with a portrait and links to further reading
- **`css/style.css`**, **`js/site.js`** — shared styling and the edition/theme toggle behavior
- **`Poetry_Curriculum_Grand_Plan.md`**, **`Poetry_Pairings_Curriculum.pdf`** — the original source material the curriculum was built from

## Running it

No build step — open `index.html` directly in a browser.

## A note on text and copyright

Poems in the public domain are reproduced in full. Poems still under copyright are described rather than reprinted, with a link to an authorized source for the complete text.
